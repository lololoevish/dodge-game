# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## Игра "Dodge Game" (веб-приложение на выживание)

---

## 1. ОБЩАЯ ИНФОРМАЦИЯ

### 1.1 Описание проекта
Полностью завершенная веб-игра на выживание, где игрок управляет синим курсором и избегает 16 различных типов игровых фигур с уникальными механиками. Игра полностью переведена на русский язык с подробными инструкциями для каждой фигуры с эмодзи-представлением. Цель - продержаться как можно дольше в постоянно усложняющейся игре с новыми противниками каждые 5-10 секунд.

**Примечание**: Фигуры с эффектами влияния на игрока (замедление и т.п.) были удалены из-за проблем с корректной работой в браузере.

### 1.2 Технологический стек
- **Фронтенд**: Next.js 15.5.3 с App Router, React 19.1.0, TypeScript 5.x
- **Стилизация**: Tailwind CSS v4, shadcn/ui компоненты
- **Шрифты**: Inter font
- **Темы**: next-themes для переключения темной/светлой темы
- **Иконки**: Lucide React
- **Рендеринг**: Canvas API для 60 FPS игровой анимации
- **Пакетный менеджер**: pnpm
- **Хранение данных**: localStorage для сохранения рекордов
- **Физика**: Кастомная реализация коллизий и движения

### 2.2 Игровые объекты

#### Игрок
- **Внешний вид**: Синий круг (12px диаметр)
- **Управление**: Мышь на десктопе, касание на мобильных
- **Поведение**: Следует за курсором/пальцем в реальном времени

#### 1. Красный квадрат-преследователь (10 сек)
- **Размер**: 20x20px
- **Поведение**: Преследует игрока, двигаясь только по осям
- **Алгоритм**: Выбирает кратчайший путь по одной оси
- **Скорость**: 2 пикселя за кадр

#### 2. Оранжевый треугольник-спиннер (15 сек)
- **Размер**: 18x18px
- **Поведение**: Быстро вращается вокруг своей оси
- **Особенность**: Статичен, но создает визуальную угрозу

#### 3. Янтарный огненный шар (20 сек)
- **Размер**: 14x14px
- **Поведение**: Движется по прямой, отскакивает от стен
- **Особенность**: Оставляет огненный след из 10 точек

#### 4. Фиолетовый пентагон-спираль (25 сек)
- **Размер**: 22x22px
- **Поведение**: Движется по расширяющейся спирали от центра
- **Особенность**: Непредсказуемая траектория

#### 5. Зеленый отскакивающий круг (30 сек)
- **Размер**: 20x20px
- **Поведение**: Движется по прямой, отскакивает от стен
- **Физика**: Угол падения = угол отражения

#### 6. Желтая молния-телепорт (35 сек)
- **Размер**: 16x16px
- **Поведение**: Телепортируется каждые 2 секунды в случайное место
- **Особенность**: Мгновенное перемещение

#### 7. Желтая звездочка-генератор (40 сек)
- **Размер**: 24x24px
- **Поведение**: Статична, стреляет 5 фиолетовыми снарядами каждые 20 секунд
- **Снаряды**: Один летит к игроку, остальные веером (8px диаметр)

#### 8. Красный маятник (45 сек)
- **Размер**: 20x20px
- **Поведение**: Качается влево-вправо по центру экрана как настоящий маятник
- **Диапазон**: 200px от центра в каждую сторону
- **Скорость**: 1.5 пикселя за кадр

#### 9. Голубая ледяная сфера (50 сек)
- **Размер**: 24x24px
- **Поведение**: Статична, замедляет все в радиусе 100px
- **Эффект**: Снижает скорость движения в 2 раза

#### 10. Темно-красная мина (55 сек)
- **Размер**: 12x12px
- **Поведение**: Статична, взрывается при приближении на 40px
- **Активация**: 3 секунды до вооружения, показывает область взрыва

#### 11. Синий диагональный охотник (60 сек)
- **Размер**: 18x18px
- **Поведение**: Умно движется по диагонали прямо к текущей позиции игрока
- **Особенность**: Обновляет цель при достижении предыдущей позиции
- **Скорость**: 1.8 пикселя за кадр

#### 12. Красный лазерный луч (70 сек)
- **Размеры**: 200px длина, 4px ширина
- **Поведение**: Вращается вокруг случайного центра
- **Особенность**: Опасная линия с центральной точкой

#### 13. Розовый телепорт-куб (80 сек)
- **Размер**: 18x18px
- **Поведение**: Телепортируется каждые 4 секунды в случайное место
- **Эффект**: Плавное исчезновение перед телепортацией
- **Особенность**: Непредсказуемое появление в любой точке поля

#### 14. Кристаллический контроллер (110 сек)
- **Размер**: 24px
- **Поведение**: Статичен, периодически испускает импульсы, которые "замораживают" других врагов на 1.5 секунды в радиусе 150px
- **Особенность**: Не представляет прямой угрозы игроку, но временно снижает общую угрозу на поле

#### 15. Призрачный дубликатор (120 сек)
- **Размер**: 18px
- **Поведение**: Копирует движения игрока с задержкой 1 секунды, создавая эффект "фантома"
- **Особенность**: Повторяет маршрут игрока с небольшими отклонениями, представляет угрозу при прямом контакте

#### 16. Зона заражения (130 сек)
- **Размер**: 30px
- **Поведение**: Преследует игрока и оставляет за собой временные зоны опасности, существующие 8 секунд
- **Особенность**: Сама по себе представляет угрозу, а также создает области, в которых игрок получает урон

### 2.3 Система бонусов
Игра включает в себя систему бонусов, которая помогает игроку выжить дольше:

| Название | Эффект | Продолжительность |
|----------|--------|------------------|
| **Невидимость (Invisibility)** | Игрок становится невидимым для врагов, но сам может видеть врагов. | 7 секунд |
| **Щит (Shield)** | Игрок становится неуязвимым к столкновениям с врагами. | 5 секунд |
| **Замедление (Slow Enemies)** | Скорость всех врагов на экране уменьшается на 50%. | 8 секунд |
| **Увеличение (Size Up)** | Размер игрока увеличивается на 50%, что усложняет уклонение. | 15 секунд |
| **Время (Extra Time)** | Игроку начисляется 10 дополнительных очков. | Мгновенно |
| **Пушка (Cannon)** | Дает игроку пушку с 20 зарядами | До использования всех зарядов |

#### Механика появления бонусов:
- **Частота**: Бонусы появляются на игровом поле каждые 20 секунд.
- **Случайность**: Тип и местоположение каждого бонуса определяются случайным образом.
- **Ограничение**: Одновременно на поле может находиться только один бонус.
- **Расположение**: Бонусы не появляются слишком близко к границам поля или к другим объектам.
- **Взаимодействие**: Игрок подбирает бонус, соприкоснувшись с ним, после чего бонус немедленно активируется.

### 2.4 Система прицеливания и пушки

#### Прицеливание
- **Активация**: Нажатие клавиши "Пробел"
- **Визуализация**: Линия прицеливания от игрока к курсору мыши
- **Прицел**: Круглый маркер в точке курсора с перекрестием
- **Ограничение**: Работает только при наличии патронов

#### Пушка-дробовик
- **Получение**: Бонус "Пушка" (Cannon)
- **Заряды**: 20 патронов
- **Стрельба**: Правая кнопка мыши (ПКМ)
- **Тип выстрела**: Дробовой (5 снарядов разлетом)
- **Урон**: 1 HP за попадание
- **Скорость снарядов**: 8 пикселей за кадр

### 2.5 Система боссов

#### Появление боссов
- **Частота**: Каждую минуту (60, 120, 180... секунд)
- **Типы боссов**: Уникальный босс для каждой минуты игры
- **Размер**: 60px диаметр
- **Здоровье**: 5 HP

#### Характеристики боссов
- **Визуализация**: Крупный круг с короной (👑) и полосой здоровья
- **Поведение**: Уникальные паттерны атаки для каждого босса
- **Фазы**: Боссы имеют 3 фазы в зависимости от оставшегося здоровья
- **Награда**: Достижения за победу над боссами

### 2.6 Условия игры
- **Поражение**: Курсор касается любой фигуры или босса
- **Победа**: Отсутствует (игра на выживание)
- **Рекорд**: Время выживания в секундах

```
    /game/

      /GameOverScreen.tsx # Экран поражения
    /theme-provider.tsx # Провайдер тем
    /theme-toggle.tsx   # Переключатель тем
  /lib
    /gameLogic.ts       # Вся игровая логика и функции
    /utils.ts           # Утилиты Tailwind
  /types
    /game.ts            # TypeScript типы для всех игровых объектов
```

### 4.2 Локальное хранение данных

#### Сохранение рекордов
- **Метод**: localStorage браузера
- **Ключ**: "dodgeGame-bestScore"
- **Формат**: Строка с количеством секунд
- **Обновление**: Автоматически при улучшении результата

#### Преимущества подхода
- Мгновенная работа без сети
- Простота реализации
- Отсутствие необходимости в аутентификации
- Приватность пользователя

### 4.3 Игровая логика

#### Обновление кадров
- 60 FPS с использованием `requestAnimationFrame`
- Единый игровой цикл `gameLoop` для обновления и рендеринга
- Оптимизированная функция `render` для отрисовки всех 16 типов фигур
- Эффективное управление состоянием через React hooks

#### Физика движения
- **Преследователь**: Движение только по осям к игроку
- **Треугольник**: Статичен с непрерывной анимацией вращения
- **Огненный шар**: Векторная физика с отражением от стен и огненным следом
- **Пентагон**: Спиральное движение с расширяющимся радиусом
- **Отскакивающий круг**: Прямолинейное движение с отражением
- **Молния**: Мгновенная телепортация каждые 2 секунды
- **Маятник**: Качается влево-вправо по центру экрана
- **Ледяная сфера**: Статична с зоной замедления
- **Диагональный охотник**: Умно движется по диагонали к цели
- **Мины**: Статичны с таймером активации и взрывом
- **Лазер**: Вращение вокруг центральной точки
- **Телепорт-куб**: Регулярная телепортация каждые 4 секунды
- **Кристаллический контроллер**: Статичен с периодическим замораживанием других врагов
- **Призрачный дубликатор**: Копирует движения игрока с задержкой
- **Зона заражения**: Преследует игрока и оставляет временные зоны опасности

#### Система коллизий
- **Круг-круг**: Для всех круглых объектов (оптимизировано - сравнение квадратов расстояний)
- **Круг-квадрат**: Для квадратных объектов
- **Специальные**: Лазерные лучи, области действия
- **Исключения**: Маятники и ледяные сферы не наносят прямого урона
- **Бонусы**: Специальная обработка для подбора бонусов
- **Производительность**: Оптимизированные алгоритмы без использования Math.sqrt

#### Управление состоянием
- React hooks (`useState`, `useRef`, `useCallback`) для игрового состояния
- localStorage для сохранения рекордов
- Глобальное состояние через props между компонентами
