## 🎯 Обзор проекта

### Концепция
**Dodge Game** — это динамичная аркадная игра на выживание, где игрок управляет фиолетовым кругом и должен уклоняться от 16 различных типов врагов с уникальными паттернами поведения. Игра построена на принципе нарастающей сложности и требует от игрока быстрой реакции и стратегического мышления.

### Ключевые особенности
- 🎮 **16 уникальных врагов** с разными механиками
- 🏆 **14 достижений** для мотивации игроков
- 🎁 **5 типов бонусов** для разнообразия геймплея
- 📈 **Динамическая сложность** — игра становится сложнее со временем
- 🌓 **Темная/светлая тема** для комфортной игры
- 📱 **PWA поддержка** — можно установить как приложение
- 🎨 **Адаптивный дизайн** для всех устройств

### Цели проекта
1. Создать увлекательную аркадную игру с высокой реиграбельностью
2. Обеспечить плавный геймплей (60 FPS) на всех устройствах
3. Реализовать прогрессивную систему сложности
4. Добавить систему достижений для долгосрочной мотивации
5. Обеспечить кроссплатформенность (десктоп + мобильные)

## ⚙️ Основные функции

### 1. Игровой процесс

#### Управление
- **Десктоп:** Движение мышью + Пробел для паузы
- **Мобильные:** Тач-управление + кнопка паузы
- **Особенности:**
  - Плавное следование за курсором/пальцем
  - Мгновенный отклик (< 16ms)
  - Предотвращение случайных касаний

#### Цель игры
Продержаться как можно дольше, уклоняясь от всех врагов. Счет = время выживания в секундах.

#### Условия поражения
- Столкновение с любым врагом (кроме случаев активного щита)
- Столкновение с зоной опасности
- Попадание снаряда врага

### 2. Система нарастающей сложности

#### Механика
- **Базовые интервалы спавна:** Каждый враг имеет свой базовый интервал
- **Динамическое уменьшение:** Каждые 5 секунд интервалы уменьшаются на 15%
- **Минимальный предел:** 300ms (0.3 секунды)
- **Формула:** `текущий_интервал = базовый_интервал × 0.85^(время_игры / 5)`

#### Визуализация
- Прогресс-бар сложности в справочнике врагов
- Градиент: зеленый → желтый → красный
- Процент скорости спавна в реальном времени

### 3. Сохранение прогресса

#### localStorage
- **Рекорды:** `dodgeGame-highScore`
- **Достижения:** `dodgeGame-achievements`
- **Счетчик игр:** `dodgeGame-gamesPlayed`
- **Встреченные враги:** Сохраняются в рамках сессии

**Эффекты:**
- Реалистичный отскок с сохранением энергии
- Изменение траектории движения
- Создание непредсказуемых ситуаций

- Пульсация бонусов
- Свечение активных эффектов
- Анимация появления врагов
- Плавные переходы

## 🎁 Система бонусов

### Типы бонусов (5 шт)

| Бонус | Эффект | Длительность | Цвет | Буква |
|-------|--------|--------------|------|-------|
| 🛡️ **Щит** | Неуязвимость к столкновениям | 5 сек | Голубой | S |
| 🐌 **Замедление** | Скорость врагов уменьшается на 50% | 8 сек | Желтый | L |
| 📏 **Увеличение** | Размер игрока увеличивается в 2 раза | 15 сек | Красный | U |
| 👻 **Невидимость** | Игрок невидим для врагов | 7 сек | Серый | I |
| ⏱️ **Время** | +10 секунд к счету | Мгновенно | Зеленый | T |

### Механика появления

#### Параметры спавна
- **Интервал:** 8 секунд
- **Случайность:** Тип и позиция определяются случайно
- **Ограничение:** Только один бонус на поле одновременно
- **Безопасная зона:** Не появляются слишком близко к краям (50px отступ)

#### Визуализация
- **Форма:** Круг диаметром 15px
- **Эффекты:**
  - Пульсирующее свечение (shadowBlur: 15px)
  - Анимация размера (±3px)
  - Изменение прозрачности (0.6-1.0)
- **Буква:** Первая буква типа бонуса (белым цветом, жирный шрифт 12px)

#### Взаимодействие
- **Подбор:** Автоматический при касании
- **Активация:** Мгновенная
- **Индикация:** Панель активных бонусов в верхней части экрана
- **Таймер:** Обратный отсчет для временных бонусов

### GitHub Pages

#### Автоматический деплой
1. Включить GitHub Pages в настройках репозитория
2. Выбрать источник: "GitHub Actions"
3. Push в ветку `main` → автоматический деплой

#### Workflow (`.github/workflows/deploy.yml`)
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v3
      - run: pnpm install
      - run: pnpm build
      - uses: peaceiris/actions-gh-pages@v3
```

#### Конфигурация
**next.config.ts:**
```typescript
const isGithubPages = process.env.GITHUB_PAGES === 'true'

const nextConfig = {
  output: 'export',
  basePath: isGithubPages ? '/dodge-game' : '',
  images: {
    unoptimized: true
  }
}
```
