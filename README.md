# 🎮 Dodge Game

> Динамичная аркадная игра на выживание с 16 уникальными врагами!

[![Next.js](https://img.shields.io/badge/Next.js-15.5-black?logo=next.js)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-19.1-blue?logo=react)](https://react.dev/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue?logo=typescript)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

---

## ✨ Особенности

- 🎯 **16 уникальных врагов** с различными паттернами поведения
- 🏆 **14 достижений** для долгосрочной мотивации
- 🎁 **5 типов бонусов** для разнообразия геймплея
- 📈 **Динамическая сложность** — игра становится сложнее со временем
- 🌓 **Темная/светлая тема** для комфортной игры
- 📱 **PWA поддержка** — установка как приложение
- 🎨 **Адаптивный дизайн** для всех устройств
- ⚡ **60 FPS** производительность

---

## 🎯 Как играть

1. **Выберите платформу** (компьютер или мобильное устройство)
2. **Управляйте фиолетовым кругом** мышью или касанием
3. **Избегайте ВСЕХ цветных фигур** и зон опасности
4. **Собирайте бонусы** для временных усилений
5. **Продержитесь как можно дольше!**

### 🎮 Управление

- **Десктоп:** Мышь + `Пробел` для паузы
- **Мобильные:** Касания экрана + кнопка паузы

## 🚀 Быстрый старт

### Требования

- Node.js 20.x (см. `.nvmrc`)
- pnpm 8.x+

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/dodge-game.git
cd dodge-game

# Установить зависимости
pnpm install

# Запустить в режиме разработки
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена

```bash
# Сборка
pnpm build

# Запуск продакшен версии
pnpm start
```

## 👾 Враги

Игра включает **16 уникальных типов врагов**, каждый со своим поведением:

| Враг | Время | Особенность |
|------|-------|-------------|
| 🟥 Преследователь | 6 сек | Движется по осям |
| 🔺 Треугольник | 10 сек | Вращается |
| 🔥 Огненный шар | 12 сек | Отскакивает от стен |
| ⬟ Пентагон | 18 сек | Спираль |
| 🟢 Круг | 20 сек | Отскакивает |
| ⚡ Молния | 22 сек | Телепортируется |
| ⭐ Звездочка | 30 сек | Стреляет снарядами |
| 💣 Мина | 35 сек | Взрывается |
| 🔷 Охотник | 40 сек | Диагональное движение |
| 📏 Лазер | 50 сек | Вращающаяся линия |
| 📦 Куб | 60 сек | Телепортация с затуханием |
| 🌀 Спиннер | 70 сек | Орбитальное вращение |
| 👻 Призрак | 80 сек | Появляется/исчезает |
| 💎 Кристалл | 110 сек | Замораживает врагов |
| 👤 Дубликатор | 120 сек | Копирует движения |
| ☢️ Зона заражения | 130 сек | Оставляет опасные зоны |

Подробнее в [PRD.md](PRD.md#враги-и-их-поведение)

## 🏆 Достижения

**14 достижений** в 3 категориях:

- ⏱️ **Временные** (6 шт) — за время выживания
- 👾 **За врагов** (4 шт) — за встречу с врагами
- ⭐ **Специальные** (4 шт) — за игры и особые условия

## 🛠️ Технологии

### Frontend
- **Framework:** Next.js 15.5.9 (App Router)
- **Runtime:** React 19.1.0
- **Language:** TypeScript 5.x
- **Styling:** Tailwind CSS v4
- **UI:** shadcn/ui
- **Icons:** Lucide React
- **Theme:** next-themes

### Игровой движок
- **Рендеринг:** Canvas API (60 FPS)
- **Физика:** Собственная система коллизий
- **Состояние:** React Hooks + Refs

## 📦 Деплой

### GitHub Pages (автоматический)

1. Включите GitHub Pages в настройках репозитория
2. Выберите источник: **"GitHub Actions"**
3. Push в `main` → автоматический деплой

### Ручной деплой

```bash
# Сборка для GitHub Pages
GITHUB_PAGES=true pnpm build

# Папка out/ содержит готовые файлы
```

### Другие платформы

- **Vercel:** Подключите репозиторий в Dashboard
- **Netlify:** Build command: `pnpm build`, Publish: `out`
